Пароль

Если поле Password заполнено, папка payload пакуется с шифрованием:

7z a -t7z -p<пароль> -mhe=on

Шифруются и данные, и заголовки архива — имена файлов тоже скрыты. Этот же пароль записывается в конфигурацию, поэтому модуль распаковывает архив без запроса.

Готовый .7z

Если payload — уже собранный архив, он не перешифровывается. В журнале появится предупреждение: архив нужно зашифровать заранее тем же паролем.

Проверка

Собранный архив открывается только с паролем: 7z t без пароля завершается с ошибкой, с паролем — успешно.
