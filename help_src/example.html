Пример

Рядом с программой лежит папка Example\:

Example\
  payload\      файлы для установщика
  example.ini   параметры
  readme.txt    краткая инструкция

Если папка есть, при запуске поля заполняются автоматически: Payload = Example\payload, Результат = Example\example.exe, остальное берётся из example.ini. Остаётся нажать «Собрать».

Свой пример

Положите файлы в Example\payload\ (или замените папку на payload.7z) и при необходимости поправьте example.ini.
