Просмотр конфигурации готового SFX

Собранный установщик состоит из трёх частей: [модуль .sfx] + [конфигурация UTF-8] + [архив 7z]. SfxPress умеет прочитать текстовую часть обратно из готового exe, чтобы проверить, что именно попало в сборку.

Как открыть

  • Меню Файл → Показать конфигурацию из SFX… — выбрать exe.
  • Перетащить готовый .exe в окно программы (перетаскивание папки или .7z по-прежнему заполняет payload).
  • Из командной строки: SfxPress.exe --show-config=<файл.exe> — текст печатается в консоль, код возврата 0 при успехе и 3 при ошибке; окно программы не показывается.

Что показывается

Конфигурация открывается на вкладке Конфигурация в режиме только для чтения, с той же подсветкой, копированием (Ctrl+A / Ctrl+C) и масштабом (Ctrl+±, Ctrl+0, Ctrl+колесо). В журнал и строку состояния пишется имя файла, размер текста и способ, которым конфигурация найдена.

Как ищется конфигурация

Модуль содержит в себе копии служебных строк и даже образец сигнатуры 7z, поэтому поиск идёт с конца:

  1. в первых 2 МБ ищется последний маркер ;!@InstallEnd@!, затем перед ним — последний маркер начала (;!@Install@!UTF-8! или ;!@Install@!ANSI!);
  2. найденный блок декодируется как UTF-8, для старых сборок — как CP1251;
  3. если маркеров нет, берётся текст перед последней сигнатурой 7z и проверяется, что в нём есть параметры;
  4. если подходящего текста нет, выводится сообщение об ошибке, а не мусор из бинарника.

Возврат к генерируемой конфигурации

Пока показан чужой конфиг, вкладка не пересобирается из полей. Вернуться к обычному режиму — Файл → Вернуться к генерируемой конфигурации.

Ограничения

  • Читается только текстовая часть: архив и модуль не разбираются.
  • Если файл собран другим инструментом и не содержит ни маркеров, ни сигнатуры 7z в первых 2 МБ, SfxPress честно скажет, что это не 7zSFX.
  • Конфигурация только читается — правки в чужой exe не записываются.
