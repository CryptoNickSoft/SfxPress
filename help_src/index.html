SfxPress

SfxPress собирает SFX-инсталляторы для модифицированного модуля 7zSFX: модуль .sfx + конфигурация в UTF-8 + архив 7z склеиваются в один exe.

Быстрый старт

  1. Payload — папка с файлами или готовый .7z.
  2. Результат — путь к будущему exe.
  3. Нажмите «Собрать».

Папки рядом с программой

ПапкаНазначение
Bin\архиватор 7z.exe, его справка 7-zip.chm, справка SfxPress
Bin\Modules\модули 7zsd_*.sfx и русская справка модуля 7zSD_RU_plus.chm
Example\готовый пример: поля заполняются автоматически

Разделы справки

  • Сборка и вкладки интерфейса, разбиение на тома — «Сборка»
  • Параметры конфигурации, тома — «Параметры»
  • Пароль — «Пароль»
  • Пример — «Пример»
  • Перенос на другой компьютер — «Портативность»
  • Просмотр конфигурации готового SFX (меню, перетаскивание, --show-config) — «Просмотр конфигурации»
