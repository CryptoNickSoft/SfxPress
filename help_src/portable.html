Портативность

Программа не требует установки: всё нужное лежит рядом с SfxPress.exe.

SfxPress\
  SfxPress.exe
  Bin\7z.exe
  Bin\7z.dll
  Bin\7-zip.chm
  Bin\SfxPress.chm
  Bin\Modules\7zsd_*.sfx
  Bin\Modules\7zSD_RU_plus.chm
  Example\...
  • Папка модулей по умолчанию — относительный путь Bin\Modules.
  • Архиватор берётся из Bin; установленный 7-Zip используется только как резерв.
  • Профили сохраняют пути внутри папки программы относительными.

Собрать комплект: portable.cmd → папка dist\SfxPress\.
